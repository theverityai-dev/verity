# Personas

| Persona | Primary needs | Demo moment |
|---|---|---|
| Executive | KPI, exceptions, profitability | management dashboard |
| Operations Manager | work, capacity, overdue tasks | operations board |
| Sales Manager | leads, pipeline, quotes, orders | opportunity → quote |
| Procurement | requisitions, POs, receipts | sourcing a shortage |
| Warehouse Operator | receiving, transfer, issue | stock movement |
| Supervisor | assignments, approvals, exceptions | resolve issue |
| Field Worker | today's work, checklist, evidence | mobile execution |
| Quality Officer | inspections and corrective actions | fail → exception |
| Finance User | invoice and payment status | commercial close |
| Administrator | users, roles, org, configuration | system control |
