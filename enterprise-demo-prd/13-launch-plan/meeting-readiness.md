# Meeting Readiness

Before any enterprise demo, verify:
- login for every demo persona;
- flagship transaction can be completed from clean seed;
- executive dashboard has meaningful populated states;
- field PWA works on phone-sized viewport;
- attachments/evidence load;
- audit timeline proves the chain;
- reset procedure is tested;
- no production credentials/endpoints exist;
- technical evidence pack is available but only shown when relevant.
