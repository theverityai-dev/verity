# Stylified (Ludhiana garment maker): what is in this folder

Read in this order.

| File | What it is |
|---|---|
| `flow.md` | The flow in seven steps, what the client's chat settled, what is configurable and where, what was cut from the brief and why, what is built |
| `plan-to-mvp-and-complete.md` | The plan: what stands, the line between client testing, go-live and a complete system, the phases, the blockers, the questions |
| `pricing.md` | Internal. The two options worked out, break-even, what the money has to cover |
| `acceptance-record.md` | The MVP measured against its acceptance criteria on the demonstration workspace |
| `demo-guide.md` | The logins, the fifteen-minute walkthrough, how to run and reset the demo |
| `Stylified_Developer_Requirements_Revised_v2.xlsx` | The client's current requirement sheet (version 2.0, 23 October 2026). The only client-written source kept |
| `proposal/` | The six-document pack sent to the client (the sixth is the acceptance walkthrough and sign-off), as HTML and PDF. See `proposal/README.md` |
| `assets/` | Generated pictures used by the demonstration and the pack (belong to this demonstration only) |

Removed on 2026-10-25 (still in git history): the first PRD and its visual blueprint, the first requirement sheet (v1.0), and the notes that
reviewed them (`prd-review-and-replan.md`, `requirement-sheet-review.md`, `demo-plan.md`, `veda-carxen-audit-and-adaptation.md`,
